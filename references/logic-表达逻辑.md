# 表达逻辑 · 先讲什么，为什么，怎么递进，怎么举例，怎么收回开头

> 这套方法真正值钱的不是句式，是**论证的顺序**。本文从他视频的完整转写里拆出逻辑链，归纳成能直接套用的规则。拆解、成稿、体检、去 AI 味，**都先过这一层**；词频、句长、AI 味指数只是后面的辅助检查。
>
> 这是篇章层。句子层（一句话里、句与句之间怎么把推理说出来）见 `syntax-长句逻辑.md`。
>
> 文中「」内是概括转述，不是原话；引用片段每处不超过 15 字。
>
> **样本（11 条）**：v1.3 四条代表作——《对轻薄手机认知》（纠偏评测）·《我又要创业了！》（个人叙事）·《过去的 48 天》（复盘）·《解构「龙虾」》（技术解读）；v1.5 增补七条——《iPhone18 Pro 上手》（购买建议+商业解读，19 分钟）·《AI 原生汽车》（概念解读+商单，31 分钟）·《万物皆可 skill》（demo 实证，12 分钟）·《Robot Phone 发布会 reaction》（双人对谈，49 分钟）·《特斯拉 Cybercab》（静态鉴赏，13 分钟）·《华为 Pura X View》（长期使用+认知正片，23 分钟，2026-10 新片）·《小鹏 L05》（体验导览，26 分钟，2026-10 新片）。

## 一、四条公理（11 条视频里都成立）

### 1. 开头先欠观众一笔账

每条视频的开头都立下一笔「后面必须还的债」，而且是具体的：

| 视频 | 开头欠下的账 | 在哪还 |
|---|---|---|
| 对轻薄手机认知 | 一个总命题（这是一场极致的权衡），加一个纠偏承诺（换掉厚度这把尺） | 换尺在 4–9% 处兑现，命题在结尾升级为行业判断 |
| 我又要创业了 | 结论先报（又创业了），再把外界四个追问原样摆上桌 | 片尾（14:02）本人出场，点名结账 |
| 过去的 48 天 | 一个场景：团队开会，日程谁也说不清，市面工具全要填表 | 结尾重演一场开会，一张图建好 9 个日程 |
| 解构龙虾 | 一个反差：技术不新，为什么这么火 | 四层原因逐层回答，结尾把「解构」升成方法 |
| iPhone18 Pro | 结论先给：「我的建议就一句话，你最好不要换」 | 原因速览三条后，「背后肯定有一套支撑的逻辑」全片展开 |
| AI 原生汽车 | 「什么叫做 AI 原生汽车」——抽象概念待解构 | 定义→机制→工程→产品逐层兑现 |
| 华为 Pura X | 「为什么一个屏幕比例的变化，体验差别这么大」 | 四层机制论证后中段点明「这就是越用越喜欢的原因」 |
| 万物皆可 skill | 「做了两个小 demo，看完 demo 再讲背后的体会」 | demo 实演还第一笔，体会全片慢慢还 |

**账有三种欠法，轻重不同**：

| 欠法 | 例 | 适合 |
|---|---|---|
| **重**：场景/命题立悬念 | 48 天的开会场景、龙虾的反差 | 个人叙事、热点解读 |
| **中**：真问题式——把观众说不清的困惑接住 | 华为条「为什么比例变化体感差别这么大」、AI 原生「什么叫做 AI 原生」 | 认知正片、概念解读 |
| **轻**：结论先行+清单式 | iPhone18「建议就一句话：最好不要换」+三条原因速览；Cybercab 三个「全球首款」清单 | 购买建议、导览 |

**2026-10 新装置：预告片式开场**。华为条和小鹏条（两条 10 月新片连续使用）的前 30–60 秒，把全片的问题碎片和结论金句先闪回一遍——拉群搜不到人、开机广告差点关不掉、「饱和式打击感官」、「与其交给人的经验不如交给技术」——然后才正式开场。观众带着拼图看全片，每个碎片出现时都是一次「还账」。

**规则**：开头那句话写完，问自己「观众现在欠着什么没听到」。答不上来，开头就是空的。预告片式碎片段里的每个碎片，后文必须真的展开。

### 2. 先立尺子，再下判断

11 条视频无一例外：**任何「好 / 坏 / 对 / 错」出现之前，先把评判标准立起来**。

- 对轻薄：先论证「该看绝对容量，不该看厚度」，四款手机才有统一的量法。
- 创业：先讲清「什么样的机会值得押上一切」，机会出现时只需逐项打勾。
- 48 天：演示完先把「它难在哪」拆成三条能力，拿同一份清单检验现成方案。
- 龙虾：产品和范式分开打分，用「听懂了多少」给观众分档。
- iPhone18：现象拆完后立「高感知+高频+高价值」三格尺，然后裁决「18 Pro 能占满三格的几乎没有」。
- 华为条：四层机制论证之后回收三格尺——「内容消耗是高频，填充率是高感知高价值」。

**尺子可以迟到，主线不能迟到**。导览型视频（Cybercab、小鹏 L05）的显式定性出现得很晚（Cybercab 在 47% 处才说「它不负责豪华，只负责把你从 A 点送到 B 点」），但全程有一条**隐式主线**（「每个设计省了什么成本」「每个物件对比例贡献什么」）先把所有细节串住。反过来，纯认知正片的尺子必须早立（对轻薄在 4–9%）。

**尺子是跨视频的资产**：iPhone18 条首次立起「高感知/高频/高价值」三格尺，华为条直接引用「我之前在上一个 iPhone 的视频当中讲过我衡量产品的三个模型」；小鹏条复用华为条的人眼视角数字（280/130/下 70–80 度）论证内饰横向线条。**立过的尺子直接回链，比重新论证省十分钟，还给系列感**。

**规则**：尺子要**可计算、可演示、可验证**；用之前先交代它的误差。判断落下来之前，尺子必须在场——不在场就补，补不出来就别下判断。

### 3. 每一段回答上一段留下的问题

段与段之间不是并列，是**问答咬合**：上一段结尾留下一个观众必然会问的问题，下一段回答它。

| 视频 | 问答链 |
|---|---|
| 解构龙虾 | 为什么火？→ 门槛降了 → 那为什么不神化？→ 智能看模型 → 那它新在哪？→ 本地化+记忆 → 那为什么手机被封、PC 被捧？→ 权限哲学 |
| 过去的 48 天 | 做出了什么？→ 演示 → 真的吗？→ 真实性声明 → 现成的不行吗？→ 替代方案逐个排除 → 那你怎么做？→ 架构 |
| 我又要创业了 | 为什么离开？→ 成长靠大势 → 大势变了吗？→ 朋友关公司 → 下半场在哪？→ 产业互联网 |
| Cybercab | 为什么敢砍成这样？→ 正向研发 → 砍掉的东西去哪了？→ 逐物件沿成本线走查 → 正向研发正正在哪？→ 商业模式对照 → 生产端怎么继续省？→ 一体压铸 |
| 华为 Pura X | 为什么体感差别大？→ 人眼构造 → 还有呢？→ 视觉错位 → 还有呢？→ F 型阅读 → 还有呢？→ 物理比例 → 这重要吗？→ 回链三格尺 |
| iPhone18 | 为什么不换？→ ID/续航/内存逐项拆 → 那发布会图什么？→ 商业驱动五维 → 那我非要买呢？→ 给条件给型号 |

**同一个问题可以连问四层**（华为条的「为什么宽一点差别大」用人眼构造、视觉错位、F 型阅读、物理比例四层机制回答）——每层独立成立又层层加固，叫**多尺同测**。

**规则**：每段写完，用一句话说出「它回答了上一段的什么」。说不出，这段就是插进来的。

### 4. 有一段删掉就会塌

每条视频都有一段**承重段**，后面所有判断都从它来：

| 视频 | 承重段 | 删掉之后 |
|---|---|---|
| 对轻薄手机认知 | 纠偏换尺（不看厚度看容量） | 退化成普通的四机横评 |
| 过去的 48 天 | 实机演示 + 真实性声明 | 架构讨论成了空中楼阁 |
| 解构龙虾 | PC 管理员权限 vs 手机沙箱 | 「本地 Agent 是 PC 基建」成了光秃秃的断言 |
| Cybercab | 商业模式对照（正向研发 vs 国内改装路线） | 后面所有成本分析失去参照系 |
| Robot Phone | **owner vs tenant 比喻**（电脑你是机主，手机你是租户） | 「去 APP 化难」只剩断言，沙箱、分流权全无根 |
| AI 原生汽车 | 摆锤论（脚本可预测 vs 推理灵活，真功夫在灰度约束） | 黑灰彩三区、harness 工程全部失去出处 |
| 华为 Pura X | 四层机制论证收进三格尺的中段回收 | 「比例就是最大价值」回到体感口号 |

注意：**承重段可以是一个比喻**（Robot Phone 的 owner/tenant），不一定是数据或论证最长的段落。比喻立住了机制，机制撑起全片。

**规则**：拆解或体检时，先找承重段。找不到，说明全片没有一个真正的论点，只是在罗列。

## 二、六种推进骨架（按题材选）

| 骨架 | 代表作 | 顺序 | 适合 |
|---|---|---|---|
| **先定尺，再测量** | 对轻薄手机认知 | 定性 → 换尺 → 讲清尺子怎么量 → 选一个基准深拆 → 其余按「对基准的回应」依次测 → 上升到行业格局 | 纠偏型评测、多对象对比 |
| **结论先行的倒叙决策链** | 我又要创业了 | 报终点+摆质疑 → 回到起点 → 立标准 → 机会出现逐项打勾 → 兑现代价 → 本人出场结账 | 个人叙事、回应质疑 |
| **成品先行，按决策组织** | 过去的 48 天 | 痛点场景 → 成品演示 → 自证真实 → 立难度标准 → 排除替代方案 → 关键决策 → 代价 → 重演开头场景 | 复盘、作品展示、教程 |
| **反差立题，层层下挖** | 解构龙虾、AI 原生汽车 | 祛魅/锚点 → 抛反差或概念 → 逐层追问原因（或逐层机制） → 灰度与约束 → 「和你有什么关系」 → 升成方法/趋势 | 热点解读、技术认知、概念科普 |
| **结论先行三步式**（轻量） | iPhone18 Pro | 结论一句话 → 原因速览两三条 →「背后有一套逻辑」→ 逐项展开（产品维度→商业维度）→ 升华 → 回到结论给条件 | 购买建议、短评、立场输出 |
| **导览型：主线+走查** | Cybercab、小鹏 L05 | 给一条主线（成本/比例） → 按实物或模块顺序逐个过，每个物件回答「对主线贡献什么」 → 中途一次显式定性 → 按主线分层归纳 → 行业判断 | 现场体验、静态鉴赏、展会导览 |

**教程/实证的轻量五级**（万物皆可 skill）：成品预告（demo）→ 拆原理（怎么做到的）→ 验证了什么概念（承重）→ 升维到行业（分水岭）→ 落到公司战略。每级都比上一级宽一圈。

**共同点**：判断都放在证据之后，预测都放在原因之后，升华都放在最后。放在前面，就成了没有根据的断言。

## 三、核心论点怎么立（观众带走的那句话）

**论点是全片可以被复述成一个句子的那个判断**。11 条样本里，论点有三种给法：

| 给法 | 原型句 | 例 |
|---|---|---|
| **审题定义式** | 「所谓的 X，它的本质是什么？在我看来，其实就是 Y」 | 对轻薄：「极致的权衡艺术」 |
| **结论先行式** | 「我的建议/判断就一句话：Y」 | iPhone18：「你最好不要换」 |
| **真问题式** | 「为什么 X 会 Y？很多人有模糊的认知，今天就来回答」 | 华为条：「为什么比例变化体感差别这么大」 |

**论点的验收三条**：
1. **可复述**：外行听完全片，能说出这句判断（「小版续航≈去年大版」这种一句话尺子是黄金形态）。
2. **有机制**：判断后面跟着「因为/机制」——现象被翻译成了机制（「AI 原生 vs 脚本智能的区别不是功能多少，是思考原点」「不是去 APP 化，是 APP 在交互序列里位置更靠后了」）。
3. **统辖后文**：后文每一段都在给这个论点供料；有一段和论点无关，就是插进来的段。

**换尺是论点的武器**：观众手里已有一把尺 A（厚度、播放量、功能清单、「这个价位差不多就行」），先核对 A 对的那一半（「它有它的道理」），再换成自己的尺 B（容量、投币率、价位÷能力）。B 必须能举例、能计算。「不是 A 而是 B」全片最多一次——11 条新样本里 5 条一次都没用，用了的也只有一次（基准 0.6 次/万字）；**纠偏不靠这个句式，靠 B 真的能算**。

**价值分层判断**：同一个功能对不同人是不同东西——iPhone18 条把「内存带宽提升 50%」分层：对按 Pro 用法用的人有价值；对 99% 普通用户无感；对国行用户（用不到苹果 AI）「几乎毫无意义」。**判断不是一刀切，按人群和条件分层给**，这是结论可信度的重要来源。

## 四、论据怎么配（拿什么支撑论点）

### 位置规则

- **绝大多数论据放在论点之后**，作证据，或把抽象概念变得看得见。
- **放在论点之前的论据只有几类**：痛点场景、对照组、成品演示、错误做法、科幻锚点（AI 原生条用《霹雳游侠》把「AI 原生」锚进集体记忆）。它们的任务是**把问题立起来**，不是证明论点。
- **同一论点可以两遍**：体验段先给实例（行车中演示 agent 座舱），讲解段再系统讲机制（agent vs 语音脚本）。第二遍不是重复，是升维——实例→机制。

### 类型与作用

| 类型 | 作用 | 例 |
|---|---|---|
| 机制推演 | 让判断有「因为」 | 自动驾驶够强 → 驾驶硬件都可简化 → 所以没有方向盘 |
| 外部科学依据 | 给体感正名 | 高清电视画幅研究、眼动追踪 F 型、A4 纸 100 年标准 |
| 亲历数字 | 让内行信服 | G7 日常代步一年多；实测内存提升 50%；参与爆胎测试 |
| 行业对照 | 排除表面解释 | 国内改装路线 vs 正向研发；安卓行情价备货 vs 苹果几年前锁价 |
| 类比 | 让外行懂，还能生出新论点 | 精装房 vs 毛坯房；owner vs tenant；健身肌肉募集；饭店吃鱼吃的是实价 |
| 比例与分层 | 机制分工一目了然 | 成本砍一半；模型上车是 50%/50%；折叠屏全球 1%、中国占 50% |
| 场景想象 | 「何为得体」的常识定义 | 有人聊天就不该语音打断；下雨就不该开窗 |
| 请观众亲测 | 把验证权交出去 | 「你去线下店拿一拿」「看看我讲的能不能跟你的真实体感对应」 |

### 三个配比规律（11 条实测）

1. **外部依据 + 亲历小故事成对出现**：华为条每层机制都是「科学依据+我自己读电子书的习惯」配对——外行信故事，内行信数据。
2. **对照组可以是行业常规做法**，且能当承重段（Cybercab 的改装 vs 正向研发）。
3. **讲完优点就补代价，讲完结论就划边界**：荣耀加了电池就讲背盖质感下降；「Demo 和真正量产最本质的区别」是朝向/延迟；「全局单手操作不可能，想都别想」。**主动交代局限是给可信度买保险**，不是示弱。

### 灰度论证（排除法的镜像）

有些问题不该排除任何一方，而是**找约束区间**：AI 原生条把「脚本（可预测无灵活）」和「自由推理（灵活不可控）」摆成钟摆两端，真功夫在「约束在可控的灰度范围内」——落地成黑区/灰区/彩区三档权限。「它不是 A 也不是 B，是在什么范围里的 A 加什么约束下的 B」——**安全、监管、取舍类话题用这个，比硬排除一个诚实**。

## 五、话题怎么转（过桥的机制）

段与段的咬合要靠过桥。11 条样本里出现过桥的六种做法，按使用频率排：

| 过桥 | 原型句 | 例 |
|---|---|---|
| **借观众之口** | 「很多朋友会问」「但是很快小伙伴们就会讲了：是不是……就会有问题呢？」 | 华为条单手操作质疑；创业条外界四个追问 |
| **编号递进** | 「这是第一个点。第二个……」「还有第三个非常关键的因素在哪里」 | 论证四连、商业五维、成本三层、工程难点清单 |
| **设问自答** | 「那么这个……对于荣耀来说的意义在哪里呢？」「接下来就是推荐环节了，推不推荐呢？」 | 段落切换的显式路标 |
| **因果推演过桥** | 「那么如果说它的自动驾驶能力足够强，那么你会发现……」「所以 that's why 你发现在这辆车里面……」 | 假设句把两段焊死：上一段的结论是下一段的前提 |
| **反差自问** | 前面越肯定，越要问「那它有没有代价」「真正的问题是……」 | 开机广告段：前面都在讲适配没问题，「真正的问题是开机广告」 |
| **推演终点变新问题** | 对轻薄的「砍摄像头」推到底，引出下一个工程难题 | 推理的尽头自然生成下一段 |
| **OK 翻页** | 「OK」「好，那接下来这部分呢」 | 大段落切换（他 OK 前停顿约 2 秒）；小鹏条 OK 2–4 次、iPhone18 条 11 次 |

**对谈形态的过桥成本由嘉宾和片源承担**：reaction 形态里发布会片段本身就是路标（片段→暂停→「他这块讲的比较有趣，我为大家拆解一下」→机制→回片源）；反方问题由嘉宾抛出，主持人接「其实你讲到这个点，刚好是我想展开讲一讲的」。

**规则**：过桥词是库存不是配额，一段一个就够；两个大段之间必须有一个说出口的路标（编号、设问、OK 或因果句），不能靠剪辑硬切。**段内句间的因果、条件、让步也要用词说出来**（见 `syntax-长句逻辑.md`）。

## 六、首尾怎么呼应

| 方式 | 做法 | 例 |
|---|---|---|
| **场景重演**（最强） | 开头的具体场景在结尾再演一遍，结果已经不同 | 48 天：开头开会没人说得清，结尾一张图建好 9 个日程 |
| **账单结清** | 开头摆出的问题，结尾由本人点名回收 | 创业：本人出场；iPhone18：回到「最好不要换」，给非要买的人条件（2T 银色 Pro Max） |
| **方法升格** | 开头对一个对象做的事，结尾抽象成方法 | 龙虾：开头给技术祛魅，结尾「看范式不看品牌」 |
| **比喻三次回收** | 一个物件在「够不着/拿到了/已拥有」三个节点出现 | 创业：橱窗里的球鞋 |
| **伏笔回收** | 前面不起眼的细节，后面变成关键理由 | AI 原生：开头霹雳游侠，结尾硫酸池那集——「车的消陨让我们伤心，因为它已是伙伴」 |
| **预告片闭环** | 开头闪回的碎片逐个兑现 | 华为条：拉群/广告/合集三个碎片都在中后段展开 |

**不是每条都闭环**：对轻薄的尺子在结尾没有再出现。写稿时把呼应当成**必须检查的一项**，不要默认会自然发生。

## 七、段内的小结构

- **四拍**：先给结论或原则 → 一个日常类比 → 换来的收益（数字或前后对比）→ 主动交代代价。
- **讲完优点就补代价**：荣耀加了电池，就讲背盖换成玻纤、质感下降。
- **先压后抬**：先如实压低对象的硬实力，再肯定它代表的方向（龙虾：看空 OpenClaw，看多本地 Agent）。
- **在质疑必然出现的位置自问自答**：展示成品后回应「现成的不行吗」；回应时把问题往上提一层，变成「你的目标是什么」。
- **术语即翻译**：每个黑话下一句就是人话（orchestrator=协调者=大项目经理；tenant=租户；HAL=硬件抽象层）。同一个词全片不超过两次。
- **判断给期限**：预测类断言自带时间框（「三年五年为计的野心第一次展示」「到明年，有无自研芯片的差距会进一步拉大」）——给可被打脸的条件。
- **公允句**：黑别人或捧自己之前先说「必须要公允地说」（胖屏不是华为发明的；GUI 对 AI 不友好但它是过渡期的兜底）。

## 八、即兴短讲的逻辑（无脚本时他怎么说清楚一件事）

> 依据：JACHZHU 切片 25 条（2026-09 至 10，直播答疑/连麦/即兴点评，每条 1–9 分钟，转写见 `corpus/clips-jachzhu/`）。无脚本的即兴**多数**是「先判断后补证据」（25 条里首句即判断约 16/24）。v1.5 曾把它和「有脚本的正片先证据后判断」对照，后一半不成立（iPhone18、Cybercab 都先给判断），而且切片入点、是非问、题材都可能制造这个顺序，详见 `thinking-思维运转.md` §一。核心论点、论据、话题转化、先后顺序在即兴里的形态如下。

### 即兴回答的四步原型（72 个应答单元里完整出现 22%）

> v1.10 补齐了 25 条切片的应答单元编码（`research/编码-切片应答单元.md`）。四步全部出现的只有 16/72，一拍结论 + 机制补课 45/72，**最普遍的是机制补课本身（89%）**；让步分层（68%）和收口三选一（56%）是最常缺的两步。下表描述的是其中一种形态，不是他即兴回答的通用结构。

| 步 | 他做什么 | 原型句 |
|---|---|---|
| 1. 一拍结论 | 判断零延迟，第一拍就落下 | 「没了」「不好干」「没有，完全没有」「做不了了，比赛已经结束了」 |
| 2. 机制补课 | 紧跟着补「为什么」：时间窗口／用户悖论／物理约束／价格透明性 | 「主要原因是塞班太成功」「老年人连外骨骼都不会穿」 |
| 3. 让步与分层 | 主动说「不排除，但概率低」「真需求存在，但个案≠商业」「对 A 成立对 B 不成立」 | 「我比较保守」「只是会延迟，两种死法而已」 |
| 4. 收口三选一 | 可执行的等待指令 ／ 通用方法论 ／ 一个比喻 | 「先别买，看我们试」「人占 80% 以上的因素」「见蚊子打蚊子」 |

### 论点在即兴里的给法

- **悖论式区分**：「有些机会叫机会，有些机会叫**属于你的**机会，这是两个区别」；「不建议选英语**专业**——但我建议学好英语」（专业≠工具）。
- **分类学纠正**：先纠正归类再谈观点——「彩礼不是自然现象，是**文化现象**」（自然消失论不成立）；「主科地位**没有被取消**，只是有人说、有人建议」（传言和事实分开）。
- **人性底座**：连答串场时用一组「为什么」铺底——外卖发达=贪便宜、游戏赚钱=贪嗔痴，「围绕人性干」。

### 论据在即兴里的给法

- **反问当尺子**：不另立标准，用一个问题把标准立起来——「能不能支撑起年出货量 10 万套、估值 100 亿以上的公司？一家能不能？」
- **算账给数字**：中老年干餐饮——「北京投资 60–100 万，外地 50 万；月纯利 2 万，25 个月回本，还得月月挣 2 万；大概率 99% 收不回」——三笔账算完结论自己站起来。
- **用户悖论推演**：产品定位与目标用户自相矛盾直接点破——「老年人连外骨骼都不会穿，先解决生活自理，再谈穿十几二十斤」。
- **个案≠商业**：真需求存在但「一家公司靠个案很难支撑可持续的商业运营」——需求与市场分层。
- **客户原声还原**：模拟谈判现场代替抽象论证——「你当客户不上网查吗？硬件成本一万二，为什么收我两万？」
- **内心戏还原**：产品经理与研发的关系——「跟研发撕的时候心里想的就是：不就是老子不会写代码吗，会写的话要你干啥」。
- **亲历密度声明资格**：被质疑时用密度回应——「全中国门店我去过几千家，东北新疆海南岛，一扎好几天，人家卖货我在旁边观察」。
- **物理定律封顶**：材料疲劳→分子级断裂→A4 纸类比→「再展开没折痕是不可能的」——先给问题上限，再在上限内评估做得好不好。
- **归谬法**：证 D 字屏独创——「这事要是别人提前两天发布，你会说是苹果抄它，可能吗？」
- **反事实开路**：评西贝——「如果西贝做得好，老罗一个人说话就是孤掌难鸣，会产生口碑反噬吗？不会的嘛」。
- **沉默大多数机制**：「无数中小消费者提了一样想法没被听见，积少成多，有人揭竿而起才群起响应——你怎么只看到揭竿的人」。

### 话题转化在即兴里的形态

- **快问快答**：每个问题独立成章，问完即答，答完即收；连答的尾部常**挂一条通用方法论**（「机会是拼出来的，不是行业报告点评出来的」「没有一家企业是被口水淹死的」）。
- **同题对照**：答完一家再摆对照组——诺基亚之败对照苹果同款决策（乔布斯「如果 iPod 注定要死，我宁愿它死在我们自己手里」），差异归因到创始人一句话。
- **演反面教材**：模仿错误示范再立正解——学空话领导「大家吃好喝好、不要重蹈覆辙、要好好复盘——讲这种话那就是屁话」→正解「大领导的核心是既懂业务又能高屋建瓴提出方案，不是打补丁」。
- **把问题推回提问者**：「这些问题不应该问博主——你的地区、消费观、家庭、婚否、能力，没人知道；这辈子最了解你的只有你自己」。
- **明示立场切换**：「第三个我要讲的问题就比较公允、比较理性」——预告接下来要平衡。

### 即兴的先讲什么后讲什么

正片的顺序约束在即兴里全部保留，只是压缩：结论先落（对应公理 1 欠账换成**先还账**）→ 机制跟上（尺子）→ 让步分层（承重）→ 收口。**没有一段是纯铺垫**——即兴里不存在「我们先来看一下背景」这种慢启动，背景全部揉进机制里讲。

## 九、逻辑链表（拆解、成稿、体检都用这张表）

| 段 | 讲什么（一句话） | 为什么放在这里（回答了上一段的什么） | 理由与证据（论据类型） | 怎么推到下一段（留下什么问题、用什么桥） | 案例（论点前还是后、作用） | 呼应谁 |
|---|---|---|---|---|---|---|

**逻辑体检六问**（体检模式先问这六个，再看句子）：

1. 开头欠了观众什么账？结尾还了吗？账是重的、中的还是轻的，配得上片长吗？
2. 第一个判断出现之前，尺子立了吗？尺子能验证吗？是立过的旧尺回链，还是新立？
3. 每一段能不能用一句话说出「它回答了上一段的什么」？有没有插进来的段？
4. **核心论点是哪句？能被外行复述吗？后面有机制吗？每一段都在给它供料吗？**
5. 每个案例是在立问题，还是在证明论点？证明用的案例是不是紧跟在论点后面？判断有没有按人群分层？
6. 承重段是哪一段？删掉它，后面会不会塌？如果删掉哪段都不塌，说明全片没有论点。

篇章层过了，再查句子层：段内句子之间的因果、条件、让步有没有用词说出来？还是剁成了一串互不相干的短句（见 `syntax-长句逻辑.md` 第五节）。
