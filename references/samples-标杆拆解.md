# 深度样例拆解（主线程精读·分钟级）

## 样例一：《我又要创业了！》——个人叙事类天花板（146万播放，17分钟）

> 类型：个人IP叙事/翻盘声明。这篇是他全部内容里情绪浓度最高、结构最精密的一篇，值得整篇背下来。

### 全片骨架：三幕剧 + 一个视角机关

**【0:00-0:33 开场30秒】三连"为什么"+ 视角邀请**
- 原文："退网这些年……问到最多的还是那三个字，为什么。为什么要离开ZEALER，为什么会欠钱，为什么要在采访当中说虎狼之词，为什么要选一条这样的路。既然你已经点了进来，那不妨换个视角，我们一起用15分钟重走这段15年的旅程。"
- 手法拆解：
  1. 先把全网对他的**负面标签原样摆上桌**（欠钱、虎狼之词）——不回避、不洗白，直接转化为悬念；
  2. "既然你已经点了进来"——点破观众心理（来看热闹的），反而赢得好感；
  3. "换个视角，我们一起重走"——宣布视角机关，为全片第二人称叙事拿到授权。
- **可复刻**：把外界对你的最大质疑列成2-4个"为什么"，然后说"既然你点了进来，不妨换个视角，我们用N分钟重走这段旅程"。

**【0:33-5:40 第一幕】第二人称沉浸叙事：你=我**
- 全程用"你"讲述自己的历史："试想一下，如果从下一秒开始，你就是我。2009年……你在这个时候毕业了。"
- 关键设计：
  1. **灾难开局**（金融危机+毕业即失业+借遍同学的钱）——先抑；
  2. **具体数字造真**："申请这份工作的人有1500个，而那个唯一被录取的幸运儿，是你"——数字让故事可信；
  3. **起伏节奏**：站稳脚跟→创业ZEALER→"一切看起来都那么顺利"→"但很快，你看到了残酷的现实"——每段以转折句咬合；
  4. **谦虚的哲学收束**："其实你所有的成长都来自于趋势的托举""阶层、阅历、事业和性格，都是你终将无法突破的局限"——在叙事高潮处主动降姿态，堵住"吹嘘"的批评通道。
- **可复刻**：把自己的职业史用"你"来讲，灾难开局→转机→成功→转折→低谷，每段之间用一个转折句咬合（"但很快""这个时候""直到"）。

**【5:40-8:20 第二幕】抉择时刻：球鞋隐喻贯穿**
- 核心装置：**橱窗里的球鞋**——"此刻的你像极了站在橱窗边的孩子……要么等到你某一天长大，要么或许你一辈子都没有办法拥有它。"而后格力机会出现："你终于有机会穿上那双球鞋了"（重复三遍强调）。
- 抉择的重量来自**成本清单**："你要顾虑你的投资人、你的家人、你的合作伙伴、你的员工""甚至让你十年的个人积累瞬间蒸发"。
- 决断句设计成短句连发："如果一定要迈出这一步，那就是现在吧。趁自己三十岁，趁一切，都还来得及。"（"趁"字三连）
- **可复刻**：给人生重大选择找一个贯穿全片的实物隐喻（球鞋/渡船/登山），在"机会出现""穿上它""穿着它走向战场"三个节点反复回收。

**【8:20-12:40 第三幕】至暗时刻 + 反转蓄力**
- 代价清单用**动作串**（一句话里一个逗号一个动作）："你转让了自己名下的股份，缴纳了税款，还了贷款，卖了车子，卖了房子，给员工发了遣散费……一个人背着包，重新踏上了新的征程。"——一句一个动作，不解释，画面自传。
- 融入细节增加可信度："脱去了所有带logo的衣服""改掉了过去说话挨夹杂英文的毛病，拿起了茶杯"——用生活细节证明妥协的真实。
- 自我问答蓄力："这一切真的值吗？……只有你自己，能感受到内心的火热。"
- **可复刻**：讲低谷时用"动作瀑布"（一句一个动作）代替形容词，再用一个自我问答把情绪压到最低点。

**【12:40-14:00 顿悟段】答案揭晓**
- "你必须做回曾经的那个手艺人，用自己讲故事的手艺，去讲述一个全新的故事"——把"拍视频"重新定义为"手艺"，为回归内容行业正名；
- 三连排比推顶："只有这个战场，才是你付出一切努力代价的原因。只有这个赛场，才是你人生加权求和的结果。也只有这个赛场，会让过往的一切，都变得值得。"（"人生加权求和"——用理科词升华人生态度，是他的标志动作）
- 生日场景收束意象："在吹灭蜡烛的一瞬间，你仿佛再次听到了比赛开场的哨声……只不过跟过往不同，这次要比赛的人是你自己。"——叙事闭环。

**【14:00-17:00 跳出叙事 → 现身说法】**
- 视角从"你"切回"我"："我会努力的去选择……我当然做不到让每个人都认同，但是我想我至少可以做到不抱怨。"
- 预设批评+防御："我不知道这个视频会不会又成为全网群嘲的对象，觉得你故作煽情、骄傲造作，这个可能要靠网友自己重判了。"——主动说出差评，稀释攻击力。
- 商业信息落地：两件事（聚焦AI应用方向 / 用AI帮传统产业数字化转型）——叙事的糖衣包着创业方向的正餐。
- 感谢名单（董总、雷总、投资人、员工、格力同仁）——利益相关方逐一安放。
- 彩蛋收尾："OK，Peace——不对，应该错了，应该是这样是不是？哈哈哈哈"——用比错手势的笑场打破煽情，防止"油腻"评价。

### 本篇金句（可直接引用）

- "倘若没有大势，你所有的努力不值一提。"

### 本篇可复刻模板（个人翻盘/重新出发声明）
1. 列出外界对你的3-4个质疑（"为什么"排比）→"既然你点了进来，换个视角，我们重走这段旅程"
2. 第二人称"你"讲故事：灾难开局→转机（放一个具体数字）→成功→转折→低谷
3. 中段插一个哲学降姿态句（"所有成长都来自趋势的托举"式）
4. 给抉择找一个贯穿隐喻，三个节点回收
5. 低谷用动作瀑布（一句一动作）
6. 答案段三连排比推向高潮，用一个理科词/商业词升华
7. 切回"我"：承认做不到完美→"但至少可以做到不抱怨"
8. 预设差评+重判权交给观众
9. 落地：接下来要做的两件事
10. 感谢名单+笑场彩蛋收尾

## 样例二：《对轻薄手机认知，不妨一起换个角度去看看？》——商业分析类范本（58万播放，28分钟）

> 类型：认知纠偏型产品分析。全片是"自造分析工具→用工具逐个拆产品→用产品验证工具"的完美闭环。

### 全片骨架：先卖"尺子"，再用尺子量四款手机

**【开场 0:00-2:30】审题→定义→比喻三连**
1. "首先我们来审题啊，所谓的AIR系列超薄手机这个新的题材，它的本质到底是什么呢？在我看来，其实就叫做极致的权衡艺术。"——**审题+定义**，30秒内给出全片论点；
2. 比喻升维："就好像要你在一百四十个字里写一篇好文章，那你就不得不考虑只有文言文才能写好了，对吧？"——用写作类比工程约束；
3. "我既要还要"——四字白话点破苹果的处境。

**【2:30-6:00 纠偏段】打掉大众认知，换上自己的尺子**
- 先立靶："很多消费者把注意力过分集中在厚度这样一个单一的参数上"→自问自答"这个事儿对还是不对呢？它对，有一定的道理，但是我觉得它其实非常的片面。"（先让半步再全收）
- 抛出新指标："衡量AIR手机真正的核心指标并不是所谓的绝对厚度，而是绝对容量。"
- 论证封口："容量是三维指标，厚度是一个二维指标……过度关注厚度等于用一个二维指标去评判一个三维的游戏，本末倒置。"——维度碾压式论证。
- **可复刻**：大众看指标A → 我提出"真正的核心指标不是A，而是B" → "用A评价是本末倒置"。B必须是自己可计算/可展示的（他后面真的用长宽高算了容量）。

**【6:00-11:00 框架段】两个挑战 + 一个自造工具**
- 第一个挑战=产品定义能力：用**思想实验**演示——"我们有没有可能把摄像头彻底干掉？结论肯定不行。那我再妥协一点，一个摄像头够不够？……最终共识：怎么用一个摄像头干三个摄像头的事儿。"——把抽象的"取舍"演成对话剧。
- 第二个挑战=工程能力：比喻"收拾行李的收纳小能手"+"购物小能手"→翻译成"集成能力与供应链支配力"。
- 自造工具登场："在正式开始之前，我还要补充一个概念，叫做绝对容量——通过官方长宽高估算的数值……一定有误差，但依旧可以帮助我们从基本面上分析。"——**先声明误差再使用工具**，堵住较真观众的嘴。

**【11:00-24:00 逐产品拆解】统一框架循环四轮**
- 苹果：容量65.8cm³→"橡皮泥立方体"实物演示（边长4cm）→二维展开定宽度75mm（"行业公认单手操作宽度上限"）→上三分之一集成度解析→"极致的秩序感和工业的美感"→"但这事儿只有苹果能干"。
- 荣耀：全部用"对苹果做加法"的反向叙事——厚度找回0.46mm（"基本等于iPhone AIR贴个膜"）→三个产品收益（握感/感知稀释/电池杠杆）→"你不要信我说的，你到线下店拿一拿，立刻感受到差异"（把验证权交给观众）。
- 三星：先夸后判——"硬件品味永远在线"+"唯一核心元器件自给自足"，但"发的太早了，上一代产品"——用发布时间差解释竞争力，不否定产品本身。
- 华为：一句话总结容量→光学下放的硬实力→得出终局判断（"能走到最后的可能只有荣耀和华为"）。
- **每轮循环的固定小结构**：容量对比（橡皮泥）→工程解析→取舍与连锁反应→生态视角评价。
- **可复刻**：多对象对比时，给每个对象套同一个模板循环，且对象之间用"攻防关系"串联（B是对A的回应），而不是平行罗列。

**【24:00-28:00 收尾】从产品回到行业格局**
- 苹果三大贡献（带动热度/砍干净给安卓留加法空间/定价给足利润空间）→历史类比："还记得苹果卖四千块的时候，国产手机没有一个能冲上三千；苹果把价格提到七八千，所有国产手机全部卖到五千以上。我相信AIR品类也会是同样的路径。"——**用历史规律给预测背书**；
- 给出时间窗口："安卓厂商大概有九到十个月的时间去占领苹果生态以外的市场机会。"
- 立场表态+预告："今年的荣耀至少第一个季度之内是安卓阵营最好的AIR产品，第二季度三星可能发布……我也会对这个品类保持持续的关注。我们下期再见。"——留钩子制造连载感。

### 本篇金句
- "它的本质到底是什么呢？在我看来，其实就叫做极致的权衡艺术。"
- "过度关注厚度，等于用一个二维指标去评判一个三维的游戏，这里边本身就是本末倒置的。"
- "容量它其实是个三维指标，厚度只是一个二维指标；容量是产品能不能做好的根因，厚度只是权衡之后的结果。"
- "就是怎么尝试用一个摄像头，但是去干三个摄像头的事儿。"
- "苹果把自己AIR产品定位到八千到一万，它是明确给了所有玩家一个足够的利润空间，让AIR一定可以成为一个有利润的新品类。"
- "只要大家刀子下足够准、足够狠，这可能会是一个很好的新的发力点。"

### 本篇可复刻模板（认知纠偏型产品/行业分析）
1. 审题："所谓的____，它的本质到底是什么？在我看来就是____"（一个提炼后的概念）
2. 一个生活比喻让定义落地
3. 打大众认知："大家都在看____，这有道理，但非常片面"
4. 抛自己的尺子："真正的核心指标不是____，而是____"，论证用"维度碾压"（二维vs三维）
5. 用思想实验/对话剧演示抽象概念
6. 自造一个可计算的指标，声明误差后开始使用
7. 对每个分析对象套同一模板循环，对象间用攻防关系串联
8. 收尾跳到行业格局：历史类比→时间窗口→立场表态→下期钩子

## 样例三：《剖析 iPhone Duo》（JACHZHU 切片，47.6万播放=切片最高，5:26）——即兴逻辑天花板

> 类型：发布前首谈+发布后验收。无脚本即兴，但结构是全切片里最完整的：**期待清单当验收清单**。语料：`corpus/clips-jachzhu/2026-09-10-剖析iPhoneDuo-5m26s.txt`。

### 全片骨架：期待三问 → 逐项验收

**【0:00-0:25 定价对赌】控制变量后提问**
- 先落判断：「苹果的折叠屏至少在今天一定是社交货币；16000 买国产折叠屏当不了社交货币，三折叠也当不了」——**结论零延迟**；
- 再主动划掉变量：「我讲的是忽略容量问题——哪怕国产 16000 买 2T、苹果 16000 只能买 256G」；
- 然后对赌提问：「如果差价在 2000 元以内，你觉得国产有什么胜算？我说的在不在理？」
- **可复刻**：先排除最容易被抬杠的变量，再把问题抛给观众——对赌式开场。

**【0:25-0:31 祛魅】**「折叠屏的形态本身不新鲜，存在很久了」+回链自己旧内容作证（「当年的 awesome 你们还记得吧」）。

**【0:31-2:01 期待三问（编号）】**发布前的期待清单：
1. 行业难点痛点其他阵营解决不了，期待苹果的供应链+工程能力解决；
2. 更大尺寸下怎样的窗口管理、交互方式才是甜蜜点；
3. **三七开定量**：「开屏之后的体验，厂商做三成，生态做七成」——安卓隔离性质做不出那七成，苹果的生态号召力能否补足。
- **可复刻**：把「重要程度」说成比例（三成/七成），观众能带走；期待清单就是后面的验收清单。

**【2:01-4:33 验收②：屏幕工程机制教学】**
- 铺机制三层：柔性 OLED 基底=特殊塑料（可折叠的前提）→ 折叠时基底与表面材料**位移**（外层圆润、内层卷曲锐利）→ 只能用胶固定→牺牲刚性→塑料感/波纹/折痕；
- **物理定律封顶**：「只要是地球上一个人类造的材料，都会疲劳——金属有金属的疲劳，塑料有塑料的疲劳→分子级断裂不可修复」；
- **A4 纸类比**：「大家玩过纸没有？一张 A4 纸你不折它就没有，只要你折了它，它就一定不可能恢复原样」——把分子级断裂翻译成人人有的经验；
- 结论封顶：「再展开没有折痕是不可能的」→ 在这个上限内评估苹果（陶瓷镀膜、像素级雕刻、硬性基底层层叠加）——「展开后有直板机的硬度触感、同时保证折叠，这才是难点，我认为非常了不起」。
- **可复刻**：先用自然规律给问题定上限，再在上限内比好坏——评估显得客观，夸也夸得有根据。

**【4:33-5:21 验收③：公允角度】明示立场切换**
- 「第三个我要讲的问题就比较公允、比较理性：不能说安卓阵营没有创新的想法」；
- **归谬法证独创**：D 字外屏「要是有人提前两天发布，你就说是苹果抄它，你觉得可能吗？这是不可能的」；
- 内屏核心空间放右侧=「典型的苹果桌面及电脑的应用逻辑」；两个 APP 组成 bundle=苹果式交互创新。

**【5:21 收口】**「这就是苹果超强的供应链和工程能力所带来的结果」——回到开头的对赌题，账结清。

### 本篇可复刻模板（新品发布前后的即兴拆解）
1. 一拍结论（社交货币判断）＋控制变量（忽略容量）＋对赌提问（2000 差价有什么胜算）
2. 祛魅（形态不新鲜，回链旧内容）
3. 期待三问编号（工程/交互/生态），给比例（三七开）
4. 发布后逐项验收；机制教学用「自然规律封顶＋生活物类比（A4 纸）」
5. 公允段明示切换，归谬法证独创
6. 收口回到开头的对赌题
