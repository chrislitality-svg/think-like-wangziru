# 示例 06 · 写稿：收藏了那么多干货，为什么还是没进步

> **用户说**：「用王自如的方式给我写一篇 2 分钟的口播稿：为什么收藏了那么多干货，还是没进步。」
>
> 下面是 skill 应该交付的样子。这篇由 Claude Opus 5.5 按 `SKILL.md` 写成，用来展示「写稿」这种用法。正文约 600 字，按每分钟 300 字念大约 2 分钟，检测器 `tools/ai_flavor_check.py` 0 分。

**收藏夹越满，你越容易以为自己在进步**

你的收藏夹里，大概躺着几百条干货：剪辑教程、理财方法、高效工作的十个习惯。可是回头想想，这一年你真正学会的，可能一只手就数得过来。今天就讲清楚一件事，为什么收藏了那么多，还是没进步。

我先说答案：因为收藏这个动作，替你把「我要去学」这件事提前奖励了。你没有学，但是你已经有了学过的感觉。

判断一个人有没有进步，大家习惯看他看了多少、存了多少。这个标准对了一小半，因为输入确实是进步的起点。但真正决定你会不会的，是另一件事：你有没有自己动手做一遍，做错了，再改过来。看懂和会做，中间隔着一次犯错。

那为什么收藏会让人停在看懂这一步？因为它太便宜了。点一下收藏，一秒钟，你的大脑就记下一笔：这个问题我已经处理了。而真正去学，要花一个晚上，要面对自己做不好的那种难受。一个一秒钟就能拿到安心感的动作，和一个要花几个小时还会让你难受的动作摆在一起，你会选哪个？大部分人会选前者，这跟懒不懒没关系，换谁都会这样选。

那是不是收藏没用？也不是。如果你收藏的时候，心里已经有一个正在做的项目，比如你下周就要剪一条视频，那你存一个转场教程，它会在下周派上用场。问题出在没有项目、只是觉得以后可能用得上的那种收藏。以后，往往就是不会再打开。

那怎么从看懂走到会做？最笨也最有效的办法，是看完一条教程，马上照着做一个最小的版本，哪怕只是一段十秒钟的视频、一张只有三行的表格。做的过程中你一定会卡住，而卡住的那个地方，才是你真正还没学会的地方。

所以下次想点收藏之前，先问自己一句：这周我要拿它做什么？答得出来，就存，然后真的去做。答不出来，就别存了，你存的不是知识，是一份不用学习的安心。

**正文后的说明**

- 问题：为什么收藏了很多干货，能力却没有提高？
- 答案：收藏提前给了「学过了」的满足感，人就停在了看懂，没走到动手做、做错、改过来。
- 根据：收藏一秒钟就能换来安心，真正学习要花几小时还会难受，两者摆在一起，人会自然选便宜的那个；有具体项目时的收藏是例外。

---

**这篇用了 skill 里的哪些做法**（展示用，正式交付时不需要这一段）

- 开头三句内说清这期回答什么，随后直接给答案。
- 换标准：从「看了多少、存了多少」换成「有没有动手做错再改」。
- 讲到怎么运作：一秒钟的安心感和几小时的难受摆在一起，人会怎么选。
- 自问自答往下推：「那为什么……」「那是不是收藏没用？」
- 例外：有具体项目时的收藏是有用的。
- 收口：落在一个能照做的问题上，结尾那句意思前文已经讲过。
