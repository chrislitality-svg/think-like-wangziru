## 一、编码规则（编码前写定）

**单元切分**
- 一个应答单元 = 一个问题 + 对它的回答，到下一个问题或明显换题为止。问题可以是听得见的提问、他复述的弹幕，或他自己设的问（「很多人认为…」「为什么…」）。
- 同一问题下的追问式自问自答（「那这有价值吗？有」）不另切。连珠炮快答按问题切。
- 切片从回答中途切入时，入点到下一个问题之间算一个单元，标「提问不可见」。
- 纯玩笑、寒暄、没有论证内容的往来标「非推理」，不进覆盖率的分母。
- 双人切片只编码王自如本人的应答；对方说的话不编码。

**四列**
1. **首句是判断**：回答的第一个完整小句，是否就是对所问问题的评价或答复：有 / 没有、能 / 不能、对 / 错、值 / 不值、「X 是 Y」式归类，或对「怎么办」类问题的规范性答复（「一定要…」「千万别…」）。判断后面紧跟让步，仍算「是」。先讲背景、常识、身份、经历、事实，或先让步再判断，算「否」。
2. **机制**：有没有解释判断为什么成立。记首次出现的时间戳和类型：用户悖论、物理 / 生理约束、算账、时间窗口、商业 / 激励、技术原理、文化、人性、筛选。类比只有用来说明因果时才算机制。
3. **让步分层**：有没有明确承认反面、例外或适用边界：「但…」「不排除」「不是不可能」「对 A 成立对 B 不成立」「如果你…也可以」。只是补充注意事项（「记得喝电解质」）不算。
4. **收口形态**：单元最后一句或最后一个完整意群，归入：**指令**（可执行建议）、**规律**（能单独引用的通则）、**比喻**、**回扣首句**（重复开头的判断）、**其他**（态度句、玩笑、结论性但不属以上三类）、**断**（话没说完就被剪断或转入下一问）。

**吻合判定**
- **四步完整吻合** = 列 1 是 + 列 2 有 + 列 3 有 + 列 4 属于指令 / 规律 / 比喻。这是 `logic-表达逻辑.md` §八 描述的原型。
- **核心吻合** = 列 1 是 + 列 2 有（一拍结论 + 机制补课，不要求让步和收口）。
- 另报每一列单独的出现率，以及「提问可见」和「提问不可见」两组的首句判断率，用来看剪辑入点的影响。

## 三、结果

`python research/scripts/clip_units.py` 的输出：

| 指标 | 结果 |
|---|---|
| 切片 / 应答单元 | 25 条 / **72 个**（METHODOLOGY 原写「约 40 个」） |
| **四步完整吻合** | **16/72（22%）**（METHODOLOGY 原写「覆盖 80% 以上」） |
| 核心吻合（一拍结论 + 机制补课） | 45/72（62%） |
| 首句是判断 | 52/72（72%） |
| 有机制补课 | 64/72（89%） |
| 有让步分层 | 49/72（68%） |
| 收口属于指令 / 规律 / 比喻 | 40/72（56%）；其余是其他 25、断 4、回扣首句 3 |
| 至少有一个完整吻合单元的切片 | 11/25 |

分组：

| 分组 | 单元 | 首句是判断 | 完整吻合 |
|---|---|---|---|
| 提问可见 | 38 | 30（79%） | 10（26%） |
| 　其中是非问（事后分） | 21 | 19（90%） | — |
| 　其中开放问（事后分） | 17 | 11（65%） | — |
| 提问是他自设的 | 8 | 7（88%） | 5（62%） |
| 提问不可见（回答中途切入） | 26 | 15（58%） | 1（4%） |
| 原笔记已有文字拆解的 10 条 | 27 | — | 2（7%） |
| 此前零编码的 15 条 | 45 | — | 14（31%） |

**读法**

1. **「四步原型覆盖 80% 以上」不成立**。四步全部出现的只有 22%，而且 16 个完整吻合里有 5 个来自同一条减肥切片（09-20）。四步不是他即兴回答的通用结构，更像是其中一种形态。
2. **真正普遍的是「有机制」**（89%）。他几乎每次都会解释为什么，这一条比「一拍结论」更稳。
3. **一拍结论是多数，但不是「零延迟、每次都」**：72% 的单元首句是判断。
4. **让步和收口是最常缺的两步**。三成单元没有让步分层；近一半单元的结尾不是指令、规律或比喻，而是态度句、自我辩护、预测，或者被剪断。
5. **剪辑入点的影响和评审报告的预期方向相反**。提问可见的单元首句是判断的比例（79%）反而高于回答中途切入的单元（58%）。也就是说，在能听到提问的地方，他确实多数先给答案。
   **问题形式的影响很大**（编码完成后事后补分，非预先写定）：38 个可见提问里，是非问 21 个，首句是判断 19 个（90%）；开放问（怎么看、为什么、往哪走）17 个，首句是判断 11 个（65%）。所以「一拍结论」有相当一部分是是非问本身带来的；但即使是开放问，也有约三分之二先给判断。开放问只有 17 个，这个 65% 的误差很大，要在完整直播回放里多取开放问才能确认。
6. **切片号会重排顺序**：4 条切片片头有剪辑预告，把后面的金句剪到最前面。如果把这些预告当成「第一拍」，就会高估「先判断」。v1.6 的首拍分析和评审报告附录 C 都没有排除这一点（09-16 那条被判为首拍即判断，实际是预告）。
7. **原笔记挑的 10 条并不比其余 15 条更吻合四步**（7% vs 31%）。这 10 条里有大段产品技术讲解（iPhone Duo、解锁机制），结构更像小型正片。四步原型最初是从笔记里少数几个快问快答片段归纳出来的。

**局限**：单人编码，没有第二编码者。单元切分、「首句是判断」和「收口属于哪类」都有判断空间，备注列写了边界情况。3 条切片里有说话人分不清的段落，已从编码中剔除，结论可能偏向能明确归属给他的段落。
